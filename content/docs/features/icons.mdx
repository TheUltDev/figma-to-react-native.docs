## Overview

The plugin provides a comprehensive icon system that allows you to import icons from popular libraries like [Iconify](https://iconify.design/) directly into your Figma designs. These icons are automatically converted to React Native components with full theme support and customizable properties.

<Callout type="info">
Icons are imported using the [Iconify](https://iconify.design/) format, which provides access to over 100,000 icons from popular icon sets like Material Design, Feather, Heroicons, and more.
</Callout>

## Icon Organization

Icons in the plugin are organized by:

- **Size**: Icons are available in three standard sizes - 16px, 24px, and 32px
- **Sets**: Icons are grouped into sets with prefixes (e.g., `mdi:` for Material Design Icons)
- **Theme Integration**: All icons support your design system's theme colors and variables

## Generated Code

When you use icons in your designs, the plugin generates clean React Native code with full TypeScript support.

### Basic Icon Usage

```tsx
import { IconCheck } from 'components/icons/heroicons/Check';

export function SuccessMessage() {
  return (
    <View style={styles.container}>
      <IconCheck
        size={24}
        color="success"
      />
      <Text>Operation completed successfully!</Text>
    </View>
  );
}
```

### Icon with Custom Props

```tsx
import { IconSettings } from 'components/icons/feather/Settings';

export function SettingsButton() {
  return (
    <Pressable onPress={handleSettings}>
      <IconSettings
        size={20}
        color="secondary"
      />
    </Pressable>
  );
}
```

### Icon Component Structure

Each generated icon component includes:

```tsx
import { Icon, type IconProps } from '../Icon';

export function IconCheck(props: IconProps) {
```

## Icon Properties

### IconProps Interface

```tsx
export interface IconProps {
  color?: IconColor | 'currentColor' | `#${string}`;
  size?: number;
  path?: string;
}
```

### Available Colors

The icon system supports a comprehensive color palette that integrates with your design system:

- **Brand Colors**: `brand`, `brand-pressed`, `brand-secondary`, `brand-tertiary`
- **Component Colors**: `component`, `component-pressed`, `component-secondary`, `component-tertiary`
- **Semantic Colors**: `success`, `danger`, `warning`
- **Interactive States**: `hover`, `pressed`, `selected`, `disabled`
- **Theme Colors**: `default`, `secondary`, `tertiary`, `inverse`
- **Custom Colors**: Hex values (`#ff0000`) or `currentColor`

### Size Options

Icons support flexible sizing:
- **Standard Sizes**: 16px, 24px, 32px (default sizes)
- **Custom Sizes**: Any numeric value for pixel dimensions
- **Responsive**: Automatically scales with your design system

## Advanced Features

### Icon Detection

The plugin automatically detects when nodes are icons based on:
- Component location in the special "Icons" page
- Naming convention with prefixes (e.g., `heroicons-outline:check`)
- Component structure and properties

### Theme Integration

Icons seamlessly integrate with your design system:

```tsx
// Automatic theme color application
<IconWarning color="warning" />

// Custom color override
<IconCustom color="#ff6b6b" />

// Inherit parent text color
<IconInfo color="currentColor" />
```

### Icon Set Management

The plugin provides utilities for:
- **Updating Sets**: Add new icons to existing sets
- **Version Control**: Track icon set versions and changes
- **Batch Operations**: Import multiple icon sets simultaneously
- **Cleanup**: Remove unused icons and optimize bundle size
