## Overview

The plugin allows you to make any node in your Figma design interactive by converting it into a pressable component. This generates React Native code using the [Pressable](https://reactnative.dev/docs/pressable) component with proper touch handling, press states, and accessibility features. Documentation coming soon. Thank you for your patience.

<Callout type="info">
Pressable components in React Native provide better touch handling than TouchableOpacity and include built-in accessibility features. They also support advanced interaction states like hover (on web) and focus.
</Callout>

## Pressable Types

The plugin supports various pressable interactions:

- **Tap** - Basic press/tap handling
- **Long Press** - Extended press detection
- **Hover** - Mouse hover states (web only)
- **Focus** - Keyboard focus handling
- **Disabled** - Non-interactive state

### Configure Pressable Properties

In the pressable panel, you can configure various interaction properties:

![Pressable Properties](https://placehold.co/510x800?text=Pressable+Properties+Panel)

#### Interaction Properties

- **onPress**: Handle tap/click events
- **onLongPress**: Handle long press events
- **onPressIn**: Handle press start events
- **onPressOut**: Handle press end events
- **onHoverIn/Out**: Handle hover events (web only)

#### State Properties

- **Disabled**: Make the element non-interactive
- **Hit Slop**: Extend the touchable area
- **Press Retention**: Control press behavior when moving

import { Pressable } from 'react-native';

export function MyPressableComponent() {
  return (
    <Pressable
      onPress={() => console.log('Pressed!')}
      onLongPress={() => console.log('Long pressed!')}
      disabled={false}
      hitSlop={8}
      style={({ pressed }) => [
        styles.container,
        pressed && styles.pressed,
      ]}>
      {/* Your content */}
    </Pressable>
  );
}
