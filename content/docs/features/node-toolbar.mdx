## Overview

The plugin provides a floating toolbar that appears when you select any node in your Figma design. This toolbar gives you quick access to powerful features like motion configuration, properties management, and component optimization. Documentation coming soon. Thank you for your patience.

<Callout type="info">
The Node Toolbar is context-sensitive and shows different tools based on the type of node you've selected (text, frame, image, etc.). It provides a streamlined workflow for configuring your designs for React Native export.
</Callout>

## Toolbar Features

The Node Toolbar includes several key tools:

- **Motion** - Add animations and transitions to your nodes
- **Properties** - Configure component properties and variants
- **Pressables** - Make elements interactive with touch handling
- **Optimization** - Optimize nodes for better performance
- **Export** - Quick export options for individual nodes
